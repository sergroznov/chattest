# Бот-ретранслятор для Telegram

Вы пишете боту, он пересылает ваш текст в нужный чат с подписью отправителя ("Клиент: ...", "Мастер: ...").

## Запуск

1. Создайте бота у @BotFather и скопируйте токен.
2. Узнайте свой ID у @userinfobot.
3. Скопируйте `.env.example` в `.env` и заполните значения.
4. Установите зависимости и запустите:

```
pip install -r requirements.txt
python bot.py
```

5. Откройте бота в Telegram, нажмите /start, выберите отправителя и пишите текст.

## Важно

- Бот может писать только тем, кто сам нажал /start у бота, и в группы, куда его добавили.
- Если `TARGET_CHAT_ID` не задан, сообщения приходят вам же в чат с ботом.
- Время сообщения всегда настоящее, его ставит Telegram.
